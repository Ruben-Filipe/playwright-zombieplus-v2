## 🤘 About

Repository for the automated testing project of the Zombie Plus application, built in the Playwright Zombie Edition course! Playwright is and open-source tool developed by Microsoft that revolutionizes test automation for web applications, offering and highly reliable approach.

## 💻 Technologies
- Node.js
- Playwright
- TypeScript
- Faker
- PostgreSQL

## 🤖 How to run

1. Clone the repository and install the dependencies
```
npm install
```

2. Run tests in headless mode
```
npx playwright test 
```

3. View the test report
```
npx playwright show-report
```
